# Magizhunthu Autos & Mobility — Website

Next.js 14 + Tailwind CSS site for Innova Crysta taxi bookings in Chennai.

## What's built
- Homepage: hero, interactive fare estimator, package grid, rate card preview
- `/pricing` — full rate card, permit fees, toll policy
- `/packages` — all tour packages
- `/packages/[slug]` — full SEO template page per destination (places covered,
  route, pricing breakdown, FAQ schema, TouristTrip schema)
- All pricing/permit logic centralized in `lib/pricing-data.ts` and
  `lib/fare-calculator.ts` — edit rates in ONE place, the whole site updates

## Run locally
    npm install
    npm run dev
Visit http://localhost:3000

## Add a new destination/package
Open `lib/pricing-data.ts`, add an entry to the `DESTINATIONS` array. A new
page at `/packages/your-slug` is generated automatically — no new files
needed.

## Fonts
Currently loaded via CSS `@import` (works everywhere, including offline
builds). Once deployed with internet access at build time, you can switch to
`next/font/google` for self-hosted, zero-layout-shift fonts — see the note
in `app/layout.tsx`.

## Connecting live Google Maps distance + toll data
See the comment block in `lib/fare-calculator.ts` — swap the demo distance
model in `FareEstimator.tsx` for a server route calling Google's Routes API
(`computeRoutes` with `extraComputations: ["TOLLS"]`). Requires a
`GOOGLE_MAPS_SERVER_KEY` environment variable, kept server-side only.

## Site structure (v2)
- `/spiritual`, `/hill-stations`, `/coastal`, `/heritage` — category listing pages
- `/places/[slug]` — 81 individual destination pages, auto-generated from `lib/trips-data.ts`
- `/circuits` — named pilgrimage & tourist circuits listing
- `/circuits/[slug]` — 15 circuit detail pages (Navagraha, Arupadai Veedu, Pancha Bhoota Sthalam, etc.)
- `/pricing` — full rate card

## Add a new place or circuit
Edit `lib/trips-data.ts` — add an entry to `PLACES[]` or `CIRCUITS[]`. A new
page is generated automatically at build time, with SEO title/description
and FAQ schema already wired up via `lib/seo-copy.ts`.

## SEO copy
All destination/circuit blurbs are generated by `lib/seo-copy.ts` using
templates that always mention "Chennai" and "Innova Crysta taxi". For your
top 10-15 highest-traffic pages, consider replacing the templated blurb
with fully custom, hand-written copy — Google favors unique content, and
templated copy across 90+ pages, while varied per place, is not as strong
as bespoke writing for your priority pages.

## Reviews (GMB)
`components/ReviewsSection.tsx` is built to pull live Google reviews via
the Places API. It currently shows a fallback until you provide your
Place ID + API key — see the comment block at the top of that file for
the exact fetch code to enable it.

## Service pages (use-case based SEO)
`/services` and `/services/[slug]` — 8 pages targeting searches by REASON
rather than destination: wedding car rental, airport pickup/drop, local
city rental, corporate & event travel, railway station transfer, hospital
visits, family functions, and NRI/long-duration rental. Edit
`lib/services-data.ts` to add more (e.g. movie/event outings, school/
college transport) — same auto-page-generation pattern as places/circuits.
